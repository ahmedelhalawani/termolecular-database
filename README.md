# Termolecular Database

The Termolecular Database is a public open source project dedicated to providing data on termolecular reactions across a wide array of temperature ranges and molecular species  

## Datasets

We have 3 datasets available: Standard, Ionic Reactions, and High Pressure Reactions.

Standard Reaction Dataset can be found at: nonionic.csv

Ionic Reaction Dataset can be found at: ionic.csv

High Pressure Reactions can be found at: k_infinity.csv, For properly formatted Latex formulas this can be found at: k_infinity_latex.csv 

## Usage

This is the code for the accompanying website http://www.termolecularreactions.org
